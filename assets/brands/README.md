# Provider marks

PNG assets from [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT license (see LICENSE).

- openai.png: static-png/light/openai-text.png (OpenAI wordmark)
- anthropic.png: static-png/light/anthropic.png (Anthropic symbol)
- chatgpt.png: static-png/light/openai.png (OpenAI knot used for ChatGPT)

Bundled locally; no runtime image requests. Marks identify the respective services. OpenAI's wordmark and ChatGPT's knot distinguish their two authentication channels.
