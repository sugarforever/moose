# Installed Skill folders

A GitHub folder or repository URL installs the complete folder at a resolved commit, retaining relative paths and exact bytes (including scripts and binary templates). Direct SKILL.md URLs retain the existing instruction-only import. Installation is atomic: any invalid entry, failed download, oversized package or missing SKILL.md rejects the whole package. No installation scripts run.

Limits: public HTTPS GitHub sources, single-segment refs or commit SHAs, 128 files, 8 directory levels, 512 KiB per file (SKILL.md 128 KiB), 4 MiB total. Reject symlinks, submodules, traversal and case-colliding paths. Snapshot the tree at a commit before downloading files; do not follow references outside the folder. Store bytes with installed metadata in SQLite; no credentials are used.

The Skills screen lists installed paths and sizes, lets the user choose one file, and previews UTF-8 text as source or identifies binary files. Only SKILL.md enters the initial prompt. The resource tool reads installed text without network access. Legacy single-file skills retain authorized remote text reads.

An enabled Skill can be copied on demand into a fresh conversation-workspace directory using skill_workspace, which returns a relative directory for read/bash. Preserve directory layout and bytes; never automatically execute scripts or install dependencies. Fresh copies avoid clobbering user files and stale bundle contents. Commands need the Termux environment and installed interpreters/dependencies. Local-file mode can read the same resources but cannot execute scripts. Uninstall removes the installed bundle and disables its instructions; workspace copies remain conversation files.

Acceptance: controlled GitHub responses prove pinned multi-file downloads, binary preservation, safety limits, atomic failures and backward compatibility. Real Harness/workspace tests prove enabled-only copies and relative script/reference access. Full verify plus PR checks must pass before merge; tag v0.4.0 only after both PRs merge.
